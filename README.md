# WpfTemplate.North
This is a starter template for a Wpf desktop application with styling & fonts, and utilizes the Prism framework. The following features and styling characterizes this template:

* MahApps.Metro Window
* Custom Titlebar 
* Blue and white colors
* Special font
* Mac-like Minimize-, Maximize/Restore-, and Close buttons
* Windows dropout window when hovering over the Maximize/Restore button, or when dragging the main window
* Prism for commanding and navigation, and it can therefore be extended with other Prism functionality further on along the development work (for instance PubSub events etc)
* It has a left bar where menu buttons could be added, a content section where Views as UserControls that resides in its own Prism Module project could be injected, and a right bar
